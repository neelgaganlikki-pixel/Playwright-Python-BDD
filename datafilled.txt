2. EMPLOYEE MANAGEMENT / PIM MODULE (features/employee.feature)
--------------------------------------------------------------------------------

Scenario 1: Add a new employee successfully (@smoke, @employee)
  - Form: PIM > Add Employee (/web/index.php/pim/addEmployee)
  - Field 1: First Name
      * Locator: input[name='firstName']
      * Pattern: "Auto" + 4 random uppercase/lowercase letters
      * Sample Filled Values: AutopoNp, AutoPIBN, AutoFgJD
  - Field 2: Middle Name
      * Locator: input[name='middleName']
      * Pattern: "Mid" + 3 random letters
      * Sample Filled Values: MidszQ, MidivM, MidqTi
  - Field 3: Last Name
      * Locator: input[name='lastName']
      * Pattern: "QA" + 4 random letters
      * Sample Filled Values: QAsNPV, QARaCE, QAlywk
  - Field 4: Employee Id
      * Locator: div.oxd-input-group:has-text('Employee Id') input
      * Pattern: 6-digit random integer between 800000 and 999999
      * Sample Filled Values: 856835, 851884, 914208
      * Note: Overwrites default low-range demo ID (e.g. 0616) to avoid collision
  - Action: Click Save (button[type='submit']:has-text('Save'))
  - Expected Result: Redirection to Personal Details page (/pim/viewPersonalDetails)

Scenario 2: Search for an existing employee by ID (@regression, @employee)
  - Form: PIM > Employee List (/web/index.php/pim/viewEmployeeList)
  - Field: Employee Id
      * Locator: div.oxd-input-group:has-text('Employee Id') input
      * Value Filled: Retrieved dynamically from 1st row of table
      * Sample Filled Values: 0399, 0295, 0454
  - Action: Click Search (button[type='submit']:has-text('Search'))
  - Expected Result: Results table displays records containing the searched ID

3. LEAVE MANAGEMENT MODULE (features/leave.feature)
--------------------------------------------------------------------------------

Scenario 1: View Leave List and apply search filter (@smoke, @leave)
  - Form: Leave > Leave List (/web/index.php/leave/viewLeaveList)
  - Filter Fields:
      * From Date: input within "From Date" group (e.g. 2026-01-01)
      * To Date: input within "To Date" group (e.g. 2026-12-31)
      * Show Leave with Status: Pre-selected defaults ("Pending Approval", etc.)
      * Leave Type: All / Specific Leave types
  - Action: Click Search (button[type='submit']:has-text('Search'))
  - Expected Result: Results container (.orangehrm-paper-container) is visible

Scenario 2: Reset leave search filter (@regression, @leave)
  - Form: Leave > Leave List (/web/index.php/leave/viewLeaveList)
  - Action: Click Reset (button[type='reset']:has-text('Reset'))
  - Expected Result: Filter resets and results container remains displayed
